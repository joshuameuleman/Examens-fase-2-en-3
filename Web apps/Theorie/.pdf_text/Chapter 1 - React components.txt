deling"
                           · Wat?
  -knoppen                    · Open source JavaScript library ontwikkeld door Meta (Facebook) om interactieve user interfaces
                        5         te maken voor Web Apps, vooral voor single-page applicaties (SPA's).

                           · Belangrijkste kenmerken:
                              · Herbruikbare componenten
                              · Virtual DOM: representatie van de UI (HTML-elementen) in het geheugen
                              · Documentatie en grote community die meebouwt aan React
                              · Multi-platform: Web, mobile, desktop
                                     · React en React Native (voor native iOS en Android apps)
                              · Uitgebreid ecosysteem: Redux, GraphQL, Next.js, Gatsby, Material UI
