N                   React Router
deling"
               · React Router is een library die routeringsmogelijkheden biedt voor React-toepassingen.
  -knoppen     · Mogelijkheden:

                  · Meerdere pagina's creëren in een single-page applicatie
                  · URL-parameters en queryreeksen verwerken
                  · Browsergeschiedenis en navigatie beheren
                  · Geneste routes en lay-outs maken
                  · Beveiligde routes voor authenticatie implementeren

N                    Frontend en backend (1)
deling"
                Vaak wil je in de views gegevens dynamisch inladen, al dan niet afkomstig uit een databank.
  -knoppen      Om dit mogelijk te maken, kun je twee projecten opzetten:

                1. Frontend-project met React
                    De componenten bevatten fetch-functies (geëncapsuleerd in de useEffect-hook, zie hoofdstuk 4)
                    om data op te halen van de backend via een URL met een poortnummer.
                   · Gebruik localhost als host indien beide projecten op dezelfde machine draaien.
                   · Het uitwisselingsformaat tussen frontend en backend is vrij te kiezen; vaak wordt JSON gebruikt.
